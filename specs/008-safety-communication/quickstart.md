# Quickstart: Safety communication

**Spec**: [spec.md](spec.md) | **Plan**: [plan.md](plan.md)

```bash
cd launcher && npm run dev                          # http://localhost:5173/
cd apps/event-reporting && npm test && npm run build
```

1. Open Event Reporting through the launcher and press **Reset demo data**.
2. Run the spec's acceptance scenarios in order ([spec.md](spec.md#acceptance-scenarios)), switching
   people from the avatar (Carla Mendes, Diego Laurent, Ana Ribeiro, Felix Tanaka, Lucas Weber, Eva
   Novak).
3. Check the list and both documents at 320px and with the keyboard, the print preview, and a clean
   browser console.
